## Overview

Design an academic and precise Swiss Style application for internship research and recruitment letter generation.
The Swiss style didn't arrive in laboratories by accident. It was pulled there — by necessity. When you're presenting dense datasets, complex nomenclature, and multi-variable relationships, decoration isn't just unhelpful, it's hostile. The International Typographic Style gave scientific publishing what it desperately needed: a grid rigid enough to hold chaos.

Columns aren't aesthetic choices — they are information architecture. Müller-Brockmann's grids were systems for managing cognitive load.

- Density: 3/10 — Airy
- Variance: 2/10 — Structured
- Motion: 4/10 — Subtle
- **Style:** Academic, Precise, Structured
- **Keywords:** scientific, academic, research, precise, structured, clean, legible, informative, professional, authoritative
- **Era:** 2026+ Conhecimento Estruturado

## Colors

- **Branco** (`#FFFFFF`) — Light surface, card backgrounds
- **Carvão / Off-Black** (`#121212` / `#1A1A1A`) — Dark surfaces, primary high-contrast text
- **Azul Científico** (`#0047AB`) — Accent highlight, active states, links and focus rings
- **Cinza Claro** (`#EFEFEF`) — Structural borders, divider lines, muted cards
- **Verde Escuro** (`#006400`) — Positive verification tags, success states
- **Vermelho Escuro** (`#8B0000`) — Deadline warnings, critical indicators
- **Amarelo Ouro** (`#FFD700`) — Attention indicators, pending analysis
- **Cinza Médio** (`#6C757D`) — Secondary text, technical metadata

## Typography

- **Display / Titles:** Swiss Grotesque (`Inter`, `Helvetica Neue`, `sans-serif`) — Weight 700, tight tracking
- **Body:** Swiss Grotesque — Weight 400, 16px/1.6 line-height, max 72ch per line
- **UI Labels / Badges:** 0.875rem, weight 500, slight letter-spacing
- **Monospace:** `JetBrains Mono`, `Consolas`, `monospace` — Code, metadata, technical values, protocol tokens

## Layout & Rules

- **Grid:** 12-column Swiss CSS Grid primary. Max-width containment: 1280px centered with 1.5rem side padding.
- **Base corner radius:** 8px (`rounded-lg` / `rounded-[8px]`).
- **Do's and Don'ts:**
  - No emojis in UI — use Lucide icon system only.
  - No pure black (`#000000`) — use off-black `#121212`.
  - No oversaturated accent colors.
  - No 3-column equal-width feature layouts — use asymmetric Swiss grid.
  - No `h-screen` — use `min-h-[100dvh]`.
  - No AI clichés ("Elevate", "Seamless", "Unleash", "Next-Gen") — use precise, authoritative, scientific terminology.
